# SoCLaaS - SoC LLM-as-a-Service Demo

This repository contains materials to demonstrate and help get starting with using SoCLaaS.

SoCLaaS API gateway is at: https://soclaas-api.comp.nus.edu.sg

Built for the SoC community, SoCLaaS provides free access to powerful LLM APIs for teaching, learning, experiments, prototypes, and the next idea you want to bring to life.
