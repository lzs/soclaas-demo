# Building a Chatbot in Python

Paste this prompt in Codex.

```
write a python chatbot script that uses an LLM API via REST.
read the API key from SOCLAAS_API_KEY env var,
versioned API root URL from SOCLAAS_BASE_URL,
append /chat/completions to the base URL to form the API endpoint,
and model from SOCLAAS_MODEL env var.
loop forever: read from stdin, print response.
use only standard library.
```
